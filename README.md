🌐 **Live Deployment:** [https://aisummarizer-nj83.onrender.com](https://aisummarizer-nj83.onrender.com)

---

## 🚀 Features

- **📄 Multi-Format Document Parsing:**
  - Extracts text seamlessly from **PDF** (`pdfplumber`), **Word documents** (`python-docx`), and plain **TXT** files.
- **🤖 Dual AI Model Summarization:**
  - **Google Gemini:** Generates student-friendly summaries with configurable lengths (*Short*, *Medium*, *Detailed*).
  - **Groq / OpenAI:** Ultra-fast summarization using `openai/gpt-oss-20b`.
- **⚖️ Side-by-Side Model Comparison:**
  - Compare summaries generated by Gemini and Groq side-by-side to get the best study insights.
- **💾 Saved Summaries & Downloads:**
  - Save favorite summaries to your personal collection.
  - Export summaries directly as `.txt` files or download the original uploaded documents.
- **🔐 User Authentication & Profile Management:**
  - Secure registration and login system.
  - Profile statistics (number of notes uploaded, saved summaries).
  - Profile update and secure password change workflows.
- **⚡ Production Ready:**
  - Pre-configured with **WhiteNoise** for high-performance static file serving and **Gunicorn** WSGI server.
  - Fully configured for deployment on **Render**.

## ⚙️ Local Development Setup

### 1. Clone the Repository
```bash
git clone https://github.com/adipat/AISummarizer.git
cd AISummarizer
```

### 2. Create and Activate Virtual Environment
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
Create a `.env` file in the root directory (refer to `.env.example`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
GROQ_API_KEY=your_groq_api_key_here
OPENAI_API_KEY=your_groq_api_key_here
DEBUG=True
```

### 5. Run Migrations & Start Server
```bash
python manage.py migrate
python manage.py runserver
```

Open your browser and navigate to `http://127.0.0.1:8000/`.

## ☁️ Deployment on Render

This project is optimized for one-click deployment on [Render](https://render.com):

1. Fork or push this repository to GitHub.
2. In the Render Dashboard, create a **New Web Service** and select this repo.
3. Use the following configuration:
   - **Environment:** `Python 3`
   - **Build Command:** `./build.sh`
   - **Start Command:** `gunicorn config.wsgi:application`
   - **Plan:** `Free`
4. Set the following **Environment Variables**:
   - `PYTHON_VERSION`: `3.11.9`
   - `DEBUG`: `False`
   - `GEMINI_API_KEY`: *(Your Google Gemini API Key)*
   - `GROQ_API_KEY`: *(Your Groq API Key)*
   - `OPENAI_API_KEY`: *(Your Groq API Key)*
5. Click **Deploy Web Service**.
